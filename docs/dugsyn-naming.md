# dugsyn CLI — 命名由来

## 名字

**dugsyn**（全称：独孤信多面体煤精组印 CLI）

## 典故

独孤信（502–557），西魏/北周名将，历任 14 个重要官职。1981 年出土的"独孤信多面体煤精组印"是一件 26 面体印章，其中 14 面刻有不同篆文，分别对应他在不同职位上使用的印信。这一件文物承载了多重身份，因此被戏称为"古代最强卷王"。

## 寓意

dugsyn CLI 吸收了各大厂 Agent 工具和教程的精髓，自研融合，正如独孤信的多面印汇聚多重角色于一身。

- **dug** — 独孤（Dugu），向这位"多面体"致敬
- **syn** — synthesis（融合），将不同来源的智慧熔于一炉

## 原则

一枚印，百家用，自成一派。
